A clean, zero-dependency client-side password generation tool designed to create cryptographically secure random passwords directly in the browser. Developed as an introductory web & security utility project.

---

## [EN] Features
* **Client-Side Only:** No data leaves the browser; passwords are generated locally using browser entropy.
* **Configurable Entropy:** Custom length, uppercase, lowercase, numbers, and special symbols.
* **One-Click Copy:** Fast clipboard integration.

---
